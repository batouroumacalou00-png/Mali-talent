# 🚀 Déploiement Mali Talent

## Étape 1: Préparer le projet
Tout est déjà prêt ! Le projet est configuré pour Railway.

## Étape 2: Connecter à Railway

1. Va sur https://railway.app
2. Clique sur "Start Project"
3. Sélectionne "Deploy from GitHub Repo"
4. Connecte ton compte GitHub
5. Sélectionne le dépôt Mali-talent

## Étape 3: Configuration Railway
Railway détecte automatiquement les configurations.

## Étape 4: Déployer
Railway va automatiquement déployer le projet.

## Étape 5: Accès public
- Frontend (l'app): https://mali-talent-api.railway.app
- API Backend: https://mali-talent-api.railway.app/api
- Santé API: https://mali-talent-api.railway.app/api/health

## Étape 6: Installation sur mobile
1. Ouvre l'URL dans le navigateur de ton téléphone
2. Clique sur le menu (3 points)
3. Sélectionne "Ajouter à l'écran d'accueil"
4. C'est installé ! 🎉
