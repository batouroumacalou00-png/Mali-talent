# ⚡ Démarrage Rapide Mali Talent

## 1️⃣ Installation locale (5 minutes)

```bash
git clone https://github.com/batouroumacalou00-png/Mali-talent.git
cd Mali-talent
npm install
npm --prefix packages/server install
npm --prefix packages/client install
npm run dev
```

👉 Ouvre http://localhost:3000

## 2️⃣ Déploiement en ligne (10 minutes)

1. Va sur https://railway.app
2. Connecte GitHub
3. Importe Mali-talent
4. C'est déployé !

## 3️⃣ Installation sur téléphone (1 minute)

1. Ouvre l'app dans le navigateur mobile
2. Clique menu → "Ajouter à l'écran d'accueil"
3. L'app est installée !
